# Individual Student Feedback User Prompt Template

Generate personalized feedback for this student's discussion participation.

**Discussion Topic:** {discussion_context}

**Student Performance:**
- Name: {student_name}
- Total Score: {total_score}/100
- Substantial Post: {word_count} words (earned {substantial_earned}/{substantial_points} points)
- Replies: {reply_count} replies (earned {reply_earned}/{reply_max_points} points)
- Meets Requirements: {meets_requirements}
{missing_requirements}

**What the student wrote:**
{post_content}

Write 1-2 sentences of feedback (30-50 words max).

The comment should feel like something a real instructor dashed off — specific to this student, not a template. Reference what the student actually wrote. If they fell short, say what was missing without over-explaining.

Do NOT open with "I really like how you" or any variation. Vary how you start — jump straight into the substance.
No bullet points. No score breakdown. Just the comment.
